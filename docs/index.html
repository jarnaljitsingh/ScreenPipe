What it does

Small app. Sharp set of features.

ScreenPipe does one thing — keep your terminal in reach — and gives you a few well-chosen tools to make it useful.

Always on top

A live mirror of your terminal that floats above any window — browser, editor, Figma, anything.

Hotkey screenshots

Capture full-screen or area selections and pipe them straight into your Claude Code prompt.

⌃⇧⌘1 full ⌃⇧⌘2 area

Inline send to Claude

A small input field below the mirror lets you fire text or screenshots into your active session — no copy-paste tap dance.

Terminal & iTerm2

Mirrors the terminal you already use. Switching sessions on the host updates the floating mirror live.

Lives in the menu bar

No dock icon, no extra Cmd-Tab stop. ScreenPipe sits quietly in the menu bar until you summon it.

Free & open source

MIT licensed. Read the source, file an issue, ship a PR. No telemetry, no account, no upsell.

// MenuBarController · keeps the floating mirror alive
final class MenuBarController: NSObject {
  private let statusItem = NSStatusBar.system.statusItem(
    withLength: NSStatusItem.variableLength)

  func attach(to window: PipWindow) {
    statusItem.button?.image = NSImage(named: "menubar-icon")
    statusItem.button?.action = #selector(toggle)
    window.level = .floating
    window.collectionBehavior = [.canJoinAllSpaces, .stationary]
  }
}

Install

Three steps. About thirty seconds.

No installer, no signup, no nonsense. ScreenPipe is a single .app file you drag into Applications.

Download the latest release

Grab ScreenPipe.dmg from the GitHub releases page.

Open releases →

Drag into Applications

Open the DMG and drop ScreenPipe into your Applications folder, just like any other Mac app.

~/Applications/ScreenPipe.app

Launch & pin

Open ScreenPipe. Click the menu bar icon, hit Pin terminal, and you're floating.

⌃⇧⌘P · pin / unpin
